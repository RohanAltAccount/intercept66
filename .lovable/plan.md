
# Add Google Sign-In

## Overview
Add Google OAuth authentication to the existing Auth page, allowing users to sign in with their Google account in addition to email/password.

## What Will Change

### Auth Page Updates
- Add a "Continue with Google" button above the email/password form
- Add a visual divider ("or") between social login and email/password options
- Handle Google OAuth loading state
- Display error messages if Google sign-in fails

### Technical Implementation

**1. Configure Social Auth**
First, I'll use the Lovable Cloud social auth configuration tool to set up Google OAuth. This will:
- Generate the lovable integration module at `src/integrations/lovable/`
- Install the `@lovable.dev/cloud-auth-js` package

**2. Update Auth.tsx**
- Import the lovable module for OAuth
- Add `handleGoogleSignIn` function using `lovable.auth.signInWithOAuth("google", {...})`
- Add Google sign-in button with proper styling (white background, Google logo)
- Add "or continue with email" divider
- Handle loading state for Google sign-in separately from email/password
